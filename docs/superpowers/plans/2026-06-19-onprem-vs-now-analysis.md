## C. 측정 일관성에 대한 입장 (개념)
- N차 반복은 **개별 회차를 같게 만들지 않는다.** 평균의 표준오차 = σ/√N 로 **추정값의 불확실성만** 줄인다(3회 ~1.7배, 5회 ~2.2배, 수확체감).
- 변동 출처: ① 모델 확률성(temperature·sampling — 추출 결정성 강화로 완화 가능) ② 측정 본연의 모호함(경계값).
- 업계 표준(역량평가센터·심리측정): 다수 평가자 + **신뢰도 계수(ICC/κ) + SEM·신뢰구간 보고 + 불안정 시 HITL + 인간 채점 대비 캘리브레이션**. → 본 시스템의 N차+신뢰구간+HITL이 이 방향. 다음 단계로 ICC 캘리브레이션(기존 `validation/norms`·`reliability-analyzer` 재사용).
- 결론: 목표는 "결정론적 단일 숫자"가 아니라 **"신뢰구간이 명시된 방어 가능한 추정치 + 전문가 확정"**.

## D. 내용(content) 평가에 대한 입장 (2-레이어)
- 현 멀티모달 루브릭은 **행동(전달)만** 평가 — 신뢰도 높고 fail-closed 친화적, 자동화 적합.
- 내용(전략 타당성·논리 우수성)은 가치가 크나 **할루시네이션 위험 최고** + 전문가 간에도 일치도 낮음.
- 채택: **2-레이어 분리** — 행동(확정 가능) / 내용(AI 초안, **인용 없으면 보류 fail-closed**, HITL 확정). 두 점수를 **합산하지 않음**. 이번에 내용평가 최소 프로토타입(`api/solar/content-eval`) 추가.

## E. 추가 루브릭 제안 (검토 결과)
- **합리적의사결정 — 영상 멀티모달 대상에서 제외(확정).** 실제 KHNP 평가에서 합리적의사결정은 **In-basket 서면(작성) 과제**로 수행되며 발표·구술 영상이 없다. 본 플랫폼은 영상(행동) 분석이 전제이므로 부적합 → 제외. (서면 평가는 별도 텍스트 채점 트랙이 맞다.)
  - 교훈: 신규 멀티모달 루브릭의 1차 적격 조건은 "**영상으로 관찰 가능한 발표·상호작용 과업인가**". 후보는 영상 시나리오가 있는 역량으로 한정.
- **영상 적격 후보(차기 검토)**: 4직급 **의사소통**(발표/대화 영상이 있을 경우), 또는 기존 3역량의 시나리오 변형. SSOT라 적격 시 데이터 추가만으로 동작.
- (로드맵) **교수 평가** — 별도 문서 `2026-06-19-instructor-evaluation-roadmap.md` (강의 영상 = 영상 적격).
