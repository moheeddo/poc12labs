# 프로덕션 아키텍처 가이드 — 클라우드 vs 온프레미스 (초보자용)

> **이 문서는 무엇인가?** 지금 만든 "리더십 역량진단 AI"를 진짜 서비스(프로덕션)로 올릴 때,
> **두 가지 방식**의 하드웨어·구성·비용을 비교합니다.
> - **시나리오 A (클라우드):** 지금처럼 TwelveLabs 같은 외부 AI를 인터넷으로 빌려 씀
> - **시나리오 B (온프레미스):** Marengo·Pegasus·Solar를 **회사 폐쇄망 안**에 직접 설치 (인터넷 0)
>
> ⚠️ **솔직한 전제:** 가격·정확한 GPU 대수·SLA는 **공개되지 않아 견적이 필요**합니다(아래 "확인 필요" 참고).
> 이 문서의 숫자는 2026년 공개 자료 기준이며, 신뢰도(높음/중간/낮음)를 함께 표기했습니다.

## 0. 먼저, 우리가 쓰는 "AI 3종"을 쉽게

이 플랫폼은 영상 1개를 분석하려고 **AI 엔진 3개**를 씁니다. 식당에 비유하면:

| 엔진 | 회사 | 쉽게 말하면 | 우리 앱에서 하는 일 |
|---|---|---|---|
| **Marengo** | TwelveLabs | **"영상 검색·요약 색인기"** (도서관 사서) | 영상을 숫자(임베딩)로 바꿔 "운전원이 버튼 누르는 장면" 같은 걸 찾음. 시선 신호 등 |
| **Pegasus** | TwelveLabs | **"영상을 보고 글로 설명하는 사람"** (해설자) | 챕터 나누기, 요약, 발표자별 행동 피드백 글 생성 (가장 무거운 모델) |
| **Solar Pro 2** | Upstage(한국) | **"한국어 글 평가 선생님"** (논술 채점자) | 전사(대본) 인용 근거로 "내용 평가" 채점 (행동 점수와 별개 레이어) |

> 📌 **핵심:** Marengo·Pegasus는 미국 TwelveLabs, Solar는 한국 Upstage. 셋 다 **클라우드로도, 폐쇄망 온프렘으로도** 쓸 수 있다는 게 이번 리서치의 결론입니다.

**모델 버전 (2026 현재, 신뢰도 높음):**
- Marengo **3.0** (2025-12-01 GA, 4시간 영상·36개 언어). 구버전 2.7은 2026-03-30 종료 → 옛 임베딩은 **재색인 필요**.
- Pegasus **1.5** (2026-04-20 GA).
- Solar Pro **2** = 31B 파라미터, 한국어 특화.

## 1. 시나리오 A — 클라우드 (지금 방식)

### 그림으로
```
 [교육장]                       [우리 서버(작음)]            [인터넷] → [외부 AI 클라우드]
 카메라/마이크 ──영상파일──▶  Next.js 웹앱 (Vercel 등) ──API──▶  TwelveLabs (Marengo/Pegasus)
                                  │                              Upstage (Solar)
                                  └── 분석결과 받아 화면·리포트 ◀──────┘
```

### 하드웨어 (아주 가벼움)
- **GPU 서버 불필요!** AI 계산은 전부 외부 클라우드가 함.
- 필요한 건: ① 영상 촬영 장비(3장 참고), ② 작은 웹 서버(또는 Vercel 같은 호스팅), ③ 인터넷.
- 영상 임시 저장용 약간의 스토리지.

### 비용 (TwelveLabs 클라우드 공개가, 신뢰도 높음)
- 색인(indexing): **$0.042/분**, 분석(Analyze): **$0.0292/분**, 임베딩: $0.042/분, 검색 $4/1000건.
- 무료 600분 제공. **예시:** 6인 토론 20분 영상 1건 ≈ 색인+분석 약 $1.4 + Solar 토큰비.
- 초기 하드웨어 투자 거의 0, **사용한 만큼만** 지불(OPEX).

### 장점 ✅ / 단점 ❌
- ✅ **싸고 빠른 시작** — GPU·전산실 불필요, 오늘 당장 됨(이미 동작 중).
- ✅ 모델 업데이트(Marengo 3.0 등)를 **자동으로** 최신 사용.
- ❌ **치명적: 영상이 회사 밖(인터넷)으로 나감** → KHNP의 **0-egress·폐쇄망 규제(국정원·산업부) 위반.**
  - 참고: Amazon Bedrock 경유도 "AWS 리전 안"일 뿐 **air-gapped(완전 폐쇄)는 아님** → 규제 미충족.
- ❌ 인터넷·외부 서비스 의존(장애·정책 변경 리스크).

> **결론:** 시나리오 A는 **PoC·데모·교육원 내부 실험**엔 완벽하지만, **본사업(민감 영상)엔 규제상 부적합.** 그래서 B가 필요합니다.

## 2. 시나리오 B — 온프레미스 폐쇄망 (본사업 목표)

### 🎯 이번 리서치 최대 수확 (신뢰도 높음, 교차검증됨)
> **TwelveLabs는 Marengo·Pegasus를 "완전 air-gapped(인터넷 0) 폐쇄망"에 설치하는 공식 배포를 제공합니다.**
> SaaS와 **똑같은 모델**, FIPS 서명 이미지, 고객 인증(IdP) 연동, 외부 의존성 0.
> 단 **셀프서비스 제품이 아니라 정부·방위용 커스텀 계약**(연락처 gov@twelvelabs.io), 가격·SLA·정확한 사이징은 비공개 → **견적 필요.**
> Upstage Solar도 **온프레미스 배포를 공식 제공**(한국 금융·공공 트랙레코드 보유, 2025-12 조달청 1호 생성형AI 공급).

즉, **세 엔진 모두 폐쇄망에 합법적으로 설치 가능한 길이 실재**합니다. 이게 본사업의 핵심 근거.

### 그림으로 (폐쇄망 = 인터넷과 물리적으로 끊긴 망)
```
┌─────────────────── KHNP 폐쇄망 (인터넷 0 · air-gap) ───────────────────┐
│                                                                        │
│  [교육장]            [앱 서버]              [GPU 추론 서버 (핵심)]       │
│  카메라/마이크 ─영상─▶ Next.js + API ──▶  ┌─ Marengo (영상검색/임베딩)  │
│                          │                ├─ Pegasus (영상분석/요약)    │
│                          │                └─ Solar Pro 2 (내용평가)     │
│                          │                   ↑ 전부 사내 GPU에서 계산   │
│                          ▼                                              │
│                    [스토리지/DB]  영상·임베딩·결과 (암호화 저장)         │
│                          │                                              │
│                    [감사로그·HSM 키관리·접근통제]                        │
│                                                                        │
│   외부 인터넷 ──✕(데이터 다이오드·단방향만)── 폐쇄망                      │
└────────────────────────────────────────────────────────────────────────┘
```

### 하드웨어 BOM (Bill of Materials, 부품 목록)

#### ① GPU 추론 서버 — **가장 비싸고 중요** (신뢰도: 모델크기=높음, 대수=중간)
"AI의 두뇌"입니다. 모델이 클수록 큰 GPU가 여럿 필요합니다.

| 모델 | 크기 | 필요 GPU(추정) | 근거 |
|---|---|---|---|
| **Pegasus** (가장 무거움) | 약 80B 파라미터 | **H100/H200 4~8장** (텐서병렬) | 80B×2byte(FP16)=160GB → 80GB GPU 1장 불가, 최소 2장·실무 4~8장 |
| **Solar Pro 2** | 31B | **H100/A100 80GB 1장** (FP8 양자화 시 48GB도) | 31B×2byte≈62GB → 80GB 1장 적재 |
| **Marengo** (임베딩) | 비공개(가벼움 추정) | **L40S 48GB / L4 24GB 1장~** | air-gap 최소 요건이 24GB GPU 1장 |

**GPU 스펙·가격 (2026, 신뢰도 높음):**
| GPU | VRAM | 전력 | 대략 가격/장 | 용도 |
|---|---|---|---|---|
| H200 | 141GB | 700W | ~$35-40K+ | Pegasus 대형 |
| H100 SXM | 80GB | 700W | ~$25-40K | Pegasus·Solar |
| A100 | 80GB | 400W | ~$15-17K(단종단계) | Solar |
| L40S | 48GB | 350W | 중가 | Marengo·보조 |
| L4 | 24GB | 72W | ~$2-3K | Marengo 임베딩(저전력) |

> 💡 **현실 권장:** PoC는 **H100/H200 1~2장 + L40S 1장**으로 시작 → 본격화 시 **DGX(8 GPU/노드)급**으로 확장.
> 8× H100 DGX 시스템은 약 **$400K+**, GPU만 ~5.6kW(700W×8) → 랙 부하 ~10kW급(냉각·UPS 별도).

#### ② 앱 서버 + ③ 스토리지/DB (신뢰도 높음)
- 앱 서버: 일반 x86 서버 1~2대(Next.js·API·작업큐). GPU 불필요.
- 스토리지: **영상이 큼.** 4K30fps 1시간 ≈ H.264 15~50GB, H.265로 40~50% 절감. 다카메라 2시간 세션 ≈ **60~200GB**.
  → **온프렘 NAS/오브젝트 스토리지**(S3 호환) + 벡터DB(임베딩) + 메타DB.
- 권장: 수십 TB급 스토리지 + 이중화.

#### ④ 네트워크·보안 (규제 핵심, 신뢰도 중간~높음)
- **망 분리:** 제어망↔IT망 사이 **에어갭 + 데이터 다이오드(단방향)** — 한국 공공 표준.
- **3분리망**(컴퓨트·관리·스토리지) — NVIDIA DGX BasePOD 참조.
- **데이터 보호:** H100/H200 **컨피덴셜 컴퓨팅**(VRAM AES-256 암호화, 오버헤드 1~7%), 저장 LUKS·전송 TLS, **불변 감사로그**, **FIPS 140-2 L3 HSM** 키관리, RBAC.
- **참조 규제:** 미 NRC RG 5.71(원전 defense-in-depth) — 한국 KINAC/원안위 기준은 별도 확인 필요.

#### ⑤ 가용성·운영 (신뢰도 중간)
- 전원·네트워크·스토리지 **이중화** + 자동 페일오버, 액티브-패시브 DR.
- **운영 인력:** 클러스터당 **1.5~2 FTE**, 모델 갱신당 **2~4주**(폐쇄망은 수동 업데이트).

### 장점 ✅ / 단점 ❌
- ✅ **0-egress 규제 완전 충족** — 영상이 회사 밖으로 안 나감(본사업 가능).
- ✅ **주권형 AI** — 외부 의존·정책변경 리스크 0, 원전 보안철학(defense-in-depth)과 정합.
- ❌ **초기 투자(CAPEX) 큼** — GPU 서버·전산실·냉각·전력·보안 구축비 수억~수십억.
- ❌ **운영 부담** — 전담 인력, 모델 업데이트 수동, 전력·냉각 관리.
- ❌ **가격·정확한 사이징 비공개** — 반드시 견적·PoC 필요.

## 4. 한눈에 비교

| 항목 | A. 클라우드 (현재) | B. 온프레미스 폐쇄망 (본사업) |
|---|---|---|
| **0-egress 규제** | ❌ 위반 | ✅ 충족 |
| **초기 투자(CAPEX)** | 거의 0 | 큼 (GPU·전산실·보안, 수억~수십억) |
| **운영비(OPEX)** | 사용량당 ($0.042/분 등) | 전력·인력·유지보수 (1.5~2 FTE) |
| **시작 속도** | 즉시 (오늘) | 수개월 (견적·구축·검증) |
| **GPU 하드웨어** | 불필요 | H100/H200 다수 + L40S + 스토리지 |
| **모델 업데이트** | 자동 | 수동 (2~4주/회) |
| **데이터 주권** | 외부 의존 | 완전 자체 보유 |
| **적합 용도** | PoC·데모·내부 실험 | **본사업·민감 영상·규제 대상** |

> **권장 로드맵:** **A로 검증·데모** → **B 견적·PoC**(H100 1~2장 소규모) → **본사업 B 확장.**
> "기다림을 준비로 전환" — A에서 인터페이스·평가 로직을 완성해두면 B로 drop-in 전환이 쉬움.

## 5. ⚠️ 반드시 확인 필요 (견적·PoC 없이는 불명)

근거주의 원칙상, **추정에 의존하는 부분**을 솔직히 명시합니다:

1. **TwelveLabs 온프렘 가격·SLA·정확한 GPU 대수** — 비공개. `gov@twelvelabs.io` 견적 필수.
2. **Pegasus 80B의 영상 1건당 실제 처리 시간·동시처리량** — 공개 벤치 없음(신뢰도 낮음). **하드웨어 PoC로 실측해야** 정량 비교 가능.
3. **Marengo 단독 GPU 사이징** — 파라미터 비공개. "24GB로 시작 가능"이 floor일 뿐.
4. **TwelveLabs air-gap이 양자화(FP8) 버전 제공 여부** — VRAM·GPU 대수에 직접 영향. 확인 필요.
5. **Solar Pro 2 온프렘:** Solar Pro 2는 **클로즈드 웨이트(API 전용)** → 진짜 air-gap은 **Upstage 온프렘 계약(가중치 프로비저닝)** 전제.
   - 대안: 공개 가중치 **Solar-Open-100B**(최소 4× A100 80GB)로 완전 자체 구축 가능(단 Pro 2와 다른 계열).
6. **한국 원자력 규제(KINAC/원안위) 구체 통제** — 미 NRC RG 5.71은 참조일 뿐, 국내 기준 별도 확인.
