# 야간 자율 Loop Engineering 결과 정리 (2026-06-20 밤 → 06-21 새벽)

> **한 줄 요약:** "알아서 개선-검증-보강 구조로 고도화" 지시로 **14개 사이클**을 자율 실행해
> 보안 P0(마스터키 노출)부터 채점 수식·데이터 무결성·접근성·디자인·카피까지 **실버그 ~190건을
> 발견→적대검증→수정→게이트→커밋**했습니다. 모든 변경은 tsc 0 · 테스트 통과 · build ✓로 잠갔고,
> 라이브 배포 후 실제로 막혔는지(보안 403 등) 검증했습니다.

## 0. 초보자용 — 이번 밤에 무슨 일이 있었나

밤사이 AI가 혼자 14번의 "점검 사이클"을 돌았습니다. 한 사이클은 이렇게 굴러갑니다:

1. **여러 AI가 동시에 코드를 뒤져** 한 종류의 문제(예: 보안 구멍, 계산 오류)를 찾습니다.
2. 찾은 것마다 **다른 AI가 "이거 진짜 버그 맞아? 반증해봐"** 라고 적대적으로 재검증합니다(가짜 경보 제거).
3. 살아남은 진짜 버그만 **수정**합니다.
4. 수정 후 **타입검사(tsc)·자동테스트·빌드** 3개 관문을 모두 통과해야 커밋합니다("된다"가 아니라 "돌아간다"를 확인).
5. 중요한 건 **실제 배포 후 라이브에서 진짜 막혔는지** 다시 확인합니다.

이 방식 덕분에 "고쳤다고 말만 하는" 게 아니라 **숫자와 런타임으로 증명된** 개선만 남았습니다.

## 1. 가장 중요한 성과 3가지 (이것만 기억하면 됩니다)

### ① 보안 — 마스터 API 키가 브라우저로 새던 P0 차단 (라이브 실증)
- **문제:** `/api/tl-token`이 TwelveLabs **마스터 API 키**를 브라우저에 그대로 내려보냈고,
  접근 검사가 허술(Origin 없으면 통과·부분문자열 매칭)해서 **curl 한 줄로 키를 탈취**해 계정을
  장악할 수 있었습니다.
- **수정:** Origin/Referer를 **정확히 일치할 때만 허용**하고, 없거나 다르면 **거부(fail-closed)**.
- **실증:** 배포 후 `curl`(Origin 없음) → **HTTP 403**, 가짜 Origin(`...attacker.com`) → **403**,
  응답에 키 노출 0. 가장 위험한 구멍이 실제로 막혔음을 라이브에서 확인.
- **남은 권고(사용자 결정 필요):** 키를 브라우저에 아예 안 보내려면 업로드를 서버 프록시로
  일원화하거나 단기 스코프 토큰 발급이 정답이지만, 직접 업로드는 Vercel 용량 제한 회피용이라
  대용량 영상 업로드가 깨질 수 있어 **트레이드오프 판단이 필요**합니다(온프렘 전환 시 자연 해소).

### ② "거짓 확정" 차단 — AI가 사람 판정을 위장하지 못하게 (dohan 1원칙)
- 내용 평가가 **보류/오류(채점 0건)** 상태인데도 '내용 평가 확정' 버튼이 활성이라,
  **채점 한 건 없는 실패 평가가 '전문가 확정 보고서'로 둔갑**할 수 있었습니다 → 실패 시 확정 버튼
  대신 '산출 보류' 안내로 차단. (iter31~33의 "AI 초안/가짜 완료 리포트 차단"과 같은 계열)
- 핵심 분석 파이프라인의 **근거 없는 점수 생성**·STAR 파서 오매칭·Hogan 척도 오류 등도 정정.

### ③ 채점·통계 정확성 — "숫자로 증명"되는 평가로
- **Cohen's d, ICC 신뢰구간, DIF 연속성보정** 등 도메인 수식 오류 정정(+회귀 테스트로 잠금).
- **거짓 성장 신호 차단:** 뒤늦게 등장한 역량을 0으로 패딩해 `[0, 8.5]`→가짜 '돌파',
  `[0,0,8]`→가짜 '향상'을 만들던 것을 **실제 채점된 세션만으로** 계산하도록 수정.
- norm(규준) 키 손실·transcript 매칭 오류·소표본 NaN 전파(공정성 판정 오염) 정정.

## 4. 의도적으로 "보류"한 것들 (churn 회피 — 사용자 판단 영역)

자율 수정이 위험하거나 트레이드오프가 있어 **일부러 손대지 않고 남긴** 항목들:

1. **tl-token 구조적 키 제거** — 서버 프록시 vs 직접 업로드(Vercel 용량) 트레이드오프 → 사용자 결정.
2. **비활성 UI(POV·강의·멀티모달) 입력검증** — 코드만 유지 상태라 활성화 시 처리 권장.
3. **디자인 패널 표면 통일(글래스 vs 불투명)** — 통일 방향이 모호(적대검증도 지적)해 보류.
4. **직책/직급 용어** — 검증 에이전트 간 권고가 충돌(둘 다 정당)해 보류.
5. **jargon 글로스(HDS·STAR·norm·M1–M5)** — 대상 사용자가 도메인 전문가라 과도한 자율 변경 회피.
6. **'수업 시작 (6인 조)'** — 제품 정의 카피(6인 토론)라 임의 변경 안 함.
