## 0. 작업 방식 (왜 믿을 수 있나)

매번 "고쳤다"고 말로 때우지 않고, **로봇(AI 에이전트) 여러 명을 동시에 풀어** 문제를 찾고 →
**다른 로봇이 "그거 진짜 문제 맞아?"라고 반박·검증**한 것만 수정했습니다(허위 경보 차단).
그리고 매번 **세 가지 자동 검사를 통과**해야 커밋:
- `tsc` = 타입 오류 0 (문법·타입이 맞나)
- `vitest` = 테스트 **205개 전부 통과** (기능이 돌아가나)
- `build` = 실제 배포용 빌드 성공 (진짜 만들어지나)

> 핵심 원칙: **"있다"가 아니라 "돌아간다"를 본다.** 선언이 아니라 숫자·실행으로 증명.

## 1. 🎨 디자인 — "AI가 만든 티" 제거 (브랜드)

**무엇을 고쳤나:** 좌상단 로고가 *원자 궤도 + 빛나는 효과 + 떠다니는 점 + "SYSTEM ONLINE" 깜빡이*였습니다.
이건 인터넷에 흔한 **"AI가 대충 만든 느낌(AI slop)"** 의 전형입니다.

**어떻게:** 화면 후보 3개를 실제로 그려서 보여드리고, 고르신 **"워드마크"**(글자 중심) 방향으로 교체.
- 로고 → `KHNP │ 인재개발원 HRDI / 리더십 역량진단 · VIDEO AI` (브랜드색 진녹색·남색만, 군더더기 0)
- 깜빡이 "SYSTEM ONLINE" → 조용한 "역량진단 2.0"
- 앱 아이콘(파비콘)도 깔끔한 "역량 측정 막대" 타일로
- 화면 곳곳의 잔여 슬롭 **11개** 제거: 민트색 글로우, "모니터 스캔라인" 줄무늬,
  "AI 반짝이(Sparkles)" 남발 → 의미 있는 아이콘(▷시작, ↻다시)으로 교체

> **비유:** 명함을 "반짝이 스티커 잔뜩"에서 "단정한 기관 로고"로 바꾼 것.

## 2. ♿ 접근성 — 눈·키보드·손가락 모두 쓸 수 있게

**용어 풀이:** **WCAG**는 "장애가 있어도 웹을 쓸 수 있게 하는 국제 기준"입니다. 공공기관은 사실상 필수.

- **글자가 너무 흐려서 안 보이던 문제 92곳 수정** (대비비 기준 미달 → 진하게).
  예) 회색 글씨가 흰 배경에서 2.5:1(거의 안 보임) → 4.5:1 이상(또렷).
- **키보드만으로 조작 불가 / 스크린리더가 못 읽던 문제 37곳 수정**:
  마우스 없이 Tab·Enter로 모든 버튼 사용, 아이콘 버튼에 이름 붙이기, 탭·팝업 구조 표시.
- **모바일에서 화면 깨짐·너무 작은 버튼 11곳 수정**:
  작은 폰에서 카드가 찌그러지던 것, 손가락으로 누르기엔 12px(너무 작음)이던 X버튼 → 32~36px로.

> **비유:** 건물에 계단만 있던 걸 **경사로·점자·큰 버튼**까지 갖춘 것.

## 3. 🛡️ 정확성·신뢰 — AI가 "거짓말" 못 하게 (가장 중요)

**용어 풀이:** **fail-open**은 "근거가 없는데도 결과를 단정해서 보여주는" 위험한 상태.
이 프로젝트의 핵심 가치(특허 포인트)는 **"AI는 화자일 뿐, 최종 판단은 사람"** 입니다.

실제로 발견·차단한 "거짓말" 사례들:
- **증거(영상 타임스탬프)도 없는데 "위험 높음"이라 단정**하던 것 → 증거 있는 것만 판정, 없으면 "근거 미확보".
- **데이터가 부족한데 신뢰도 0을 "실측 0"인 양** 빨간 게이지로 → "미산출"로 정직하게.
- **AI 자동 점수가 "전문가가 확정한 최종 점수"인 척** 대시보드·PDF로 흘러가던 것
  → **'AI 초안 · 전문가 확정 필요'** 라벨을 데이터 끝까지 붙임(이게 가장 큰 구조 수정).
- **백엔드(영상분석 서버)가 죽었는데 가짜 점수 6점으로 "분석 완료"** 라 표시 → 에러를 정직하게 노출.
- **"신뢰도 85%"가 사실은 범주(상/중/하)를 숫자처럼 꾸민 것** → "범주 환산값"이라 명시.
- 그 외 **진짜 버그 10개**(영상 클릭 시 앱이 멈추던 크래시, 증거맵이 항상 비던 치명 버그 등) 수정.

> **비유:** AI에게 **"근거 없으면 입 다물어"** 라고 강제한 것. 의료·원자력처럼 사람이 최종 책임.

## 4. 🧰 견고성·테스트·성능

- **견고성(harden) 9곳:** 외부 AI(TwelveLabs·Solar) 응답이 이상해도 앱이 안 깨지게 방어,
  화면에 "NaN%" 같은 깨진 값이 안 뜨게.
- **테스트 정리:** 가끔 무작위로 실패하던 테스트(flaky)를 **원인 제거**하고(파일 충돌),
  방금 고친 버그들이 **다시 생기면 자동으로 잡히도록 회귀 테스트 11개 추가**.
- **성능(속도) — 숫자로 증명:**
  | 지표 | 전 | 후 |
  |---|---|---|
  | **첫 화면 표시 속도(LCP)** | 1218ms | **1041ms (−14.5%)** |
  | 화면 밀림(CLS) | 0 | 0 (완벽 유지) |

  방법: 폰트 로딩 방식 개선 + 불필요한 무한 애니메이션 제거 + 무거운 분석 화면은 **필요할 때만 로드**.
